# My Deck 需求拆分與工時估算

- 文件版本：V0.13
- 本次範圍：保留既有任務，按十項確認方案更新 **REQ-004「教師上傳 PPT 課件」**
- 需求依據：`docs/requirements.md` V0.11、`docs/permissions.md` V0.4
- 估算口徑：以 **OpenCode AI 開發代理自身直接執行**為基準，每項工時包含該互動所需的設計、開發、自測及調整；不是人類開發團隊的人天估算
- 估算前提：開發環境、依賴、資料庫及基本前後端腳手架可直接使用；不包含等待確認、環境故障、第三方帳號審批、未拆分 REQ 或整個項目總工時
- 拆分狀態：REQ-001 共 32 項、45 小時；REQ-002 共 13 項、16.5 小時；NFR-012～NFR-013 共 2 項、4.5 小時；REQ-003 共 15 項、21.5 小時；REQ-004 共 18 項、31.5 小時；REQ-005 至 REQ-018 尚未拆分

## 1. 本次交付邊界

### 1.1 本次包含

1. 未登入使用者進入註冊頁，填寫 2–30 字元顯示名稱。
2. 只支援香港 `+852` 手機號碼或電子郵件作為註冊及登入識別。
3. 選擇老師或學生角色，註冊後不可自行修改角色。
4. 使用 8–64 個 Unicode 字元及 `zxcvbn` 至少 3 分的密碼規則。
5. 註冊及忘記密碼的手機／電郵擁有者驗證碼發送、校驗、重發及失敗處理。
6. 註冊驗證成功後啟用帳號、自動登入並進入對應角色首頁。
7. 必填、格式、密碼強度及帳號唯一性校驗，安全重試及防止重複提交。
8. 使用已驗證手機號碼或電子郵件和密碼登入。
9. 7 天無活動失效、活動續期、30 天最長工作階段及失效處理。
10. 同一帳號及來源 IP 連續失敗 5 次後限制登入 15 分鐘。
11. 忘記密碼、重設密碼及成功後撤銷全部工作階段。
12. 老師及學生首頁右上只顯示個人圖標及暱稱；點擊圖標開關只含「個人中心」及「登出」的選單；個人中心只顯示本人顯示名稱及角色，目前裝置登出及跨角色存取拒絕。
13. 已登入老師進入本人課程頁，點擊「建立課程」，只填寫 1–50 字元課程名稱；已修改表單取消時須確認放棄。
14. 提交合法課程資料，由服務端建立課程、指定當前老師為負責人並產生固定的 8 位唯一課程碼。
15. 建立成功後展示、複製課程碼及進入課程；本人課程列表按建立時間由新至舊排列。
16. 必填及長度校驗、同名課程、重複提交、課程碼碰撞、服務失敗及跨角色／跨課程存取控制。
17. 以 React + Mantine 建立統一主題，參考 Pear Deck 的明亮、圓潤及友善風格，並套用到已拆分的註冊、登入及課程介面。
18. 全域介面長度使用 `rem`，以 `0.5rem` 為最小設計單位，覆寫不合規的 Mantine 預設尺寸；僅線高及 `0.0625rem` 細邊框按已確認例外處理。
19. 已登入學生點擊「加入課程」、輸入自動 trim 及轉大寫的 8 位課程碼；已輸入時取消須確認放棄。
20. 服務端校驗學生身份、課程碼及課程狀態，免審批建立唯一成員記錄；成功後展示課程名稱、老師、課程碼及進入操作。
21. 重複加入保留原記錄；無效碼、不可加入、服務失敗及網絡重試有明確回饋；無效嘗試按帳號及 IP 可配置限流。
22. 學生列表按加入時間由新至舊；加入後只看基本資料及課堂入口，不下載原始 PPT 或查看完整成員名單；加入課程不自動加入課堂。
23. 已登入老師在本人課程點擊「上傳課件」，以單檔選擇器選擇、重選或移除一個 `.ppt`／`.pptx`；上傳前取消免確認，上傳中取消須確認。
24. 前後端以 100 MiB／104,857,600 bytes 為統一上限並校驗實際格式；顯示真實進度與校驗中狀態，同一上傳操作重試保持冪等。
25. 原檔保存於香港私有儲存，拒絕超過 100 頁、損毀、偽造、加密或需密碼的課件；合法課件建立獨立版本及待轉換記錄後才顯示成功。
26. 中斷及服務失敗後從頭重試，不支援暫停或續傳；無效及未完成檔案不進正式列表，只保留必要安全日誌，不留下半完成記錄。
27. 列表按上傳時間由新至舊顯示檔名、大小、頁數、時間及狀態；不同操作允許同名或同內容版本，僅負責老師可授權存取本人原檔。

### 1.2 本次不包含

- 管理員公開註冊、系統初始化管理員或管理員建立／停用其他管理員的實作；規則已確認，但屬後續管理員功能拆分。
- 管理員建立老師／學生帳號、批量建號及管理員修改他人角色。
- 驗證碼登入；註冊及密碼重設的擁有者驗證不等同驗證碼登入。
- `+852` 以外的國家或地區手機號碼、國際號碼庫及多地區格式適配。
- 第三方登入、其他自助帳號恢復方式、單一登入、「登出所有裝置」及完整裝置管理。
- SMS／電郵供應商帳號申請、實名審批、模板審批、費用採購及正式發送額度申請。
- 透過邀請連結、QR Code、管理員批量匯入或老師直接新增成員加入課程；本期 REQ-003 只包含學生輸入課程碼。
- 學生退出課程、查看完整成員名單、老師以學生身份加入課程、課程加入審批及自訂課程碼有效期。
- 課程描述、封面、學期等額外欄位；課程編輯、封存、刪除、共同授課、轉移負責人及管理員干預。
- 重新生成或作廢課程碼、自訂課程碼有效期；僅保留後續擴充能力。
- PPT／PPTX 的背景轉換、逐頁預覽、轉換狀態輪詢、5 分鐘轉換時限及失敗後重新轉換，屬 REQ-005；REQ-004 只交付上傳、校驗、原檔保存及待轉換記錄。
- 拖曳上傳、多檔批量上傳、雲端匯入、上傳中暫停／續傳，以及課件重新命名、刪除、覆蓋或內容去重；不同上傳操作的同名或同內容檔案按已確認規則建立獨立版本。
- 動畫、音訊、影片及原始 PPT 編輯能力；本期只保存原檔供後續擴充，不因保留原檔而交付這些展示能力。
