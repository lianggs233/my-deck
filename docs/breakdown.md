- 文件版本：V0.21
- 本次範圍：保留全部既有任務與工時，按使用者「改用python」確認後端採 FastAPI／SQLAlchemy／Celery，並補上 NFR-014 的 OpenAPI／JSON Schema 契約及 `zxcvbn` 跨語言兼容驗收
- 需求依據：`docs/requirements.md` V0.16、`docs/permissions.md` V0.6、`docs/tech-stack.md` V0.2
- 估算口徑：以 **OpenCode AI 開發代理自身直接執行**為基準，每項工時包含該互動所需的設計、開發、自測及調整；不是人類開發團隊的人天估算
- 估算前提：開發環境、依賴、資料庫及基本前後端腳手架可直接使用；不包含等待確認、環境故障、第三方帳號審批、未拆分 REQ 或整個項目總工時
- 拆分狀態：REQ-001 共 32 項、45 小時；REQ-002 共 13 項、16.5 小時；NFR-012～NFR-013 共 2 項、4.5 小時；REQ-003 共 15 項、21.5 小時；REQ-004 共 18 項、31.5 小時；REQ-005 共 22 項、41 小時；REQ-006 共 12 項、20.5 小時；REQ-007～REQ-018 共 216 項、330.5 小時；全部功能需求已完成首輪拆分，功能業務假設已按建議方案定稿；NFR-014 技術約束由現有任務吸收，不另增工時；NFR-015 新增 2 項、4 小時前端建置及品質檢查任務；管理員詳細權限及外部服務依賴仍待後續確認

## 1. 本次交付邊界

### 1.1 本次包含

1. 未登入使用者進入註冊頁，填寫 2–30 字元顯示名稱。
2. 只支援香港 `+852` 手機號碼或電子郵件作為註冊及登入識別。
3. 選擇老師或學生角色，註冊後不可自行修改角色。

5. 註冊及忘記密碼的手機／電郵擁有者驗證碼發送、校驗、重發及失敗處理。

7. 必填、格式、密碼強度及帳號唯一性校驗，安全重試及防止重複提交。
8. 使用已驗證手機號碼或電子郵件和密碼登入。
9. 7 天無活動失效、活動續期、30 天最長工作階段及失效處理。
10. 同一帳號及來源 IP 連續失敗 5 次後限制登入 15 分鐘。
11. 忘記密碼、重設密碼及成功後撤銷全部工作階段。

19. 已登入學生點擊「加入課程」、輸入自動 trim 及轉大寫的 8 位課程碼；已輸入時取消須確認放棄。
20. 服務端校驗學生身份、課程碼及課程狀態，免審批建立唯一成員記錄；成功後展示課程名稱、老師、課程碼及進入操作。

35. 斷線、重新整理及重複連線後以服務端快照恢復當前頁、活動、權限及可見標註，訪客只憑唯一 ID 恢復，不重複提交任何互動。

37. 老師直接建立共享標註並授予／收回多名學生當前課堂權限；被授權學生管理本人共享標註，作者所有權、即時同步及離線失敗均可驗收。

39. 老師篩選、隱藏、顯示及經確認清除本人課堂共享標註；新加入和重連端只恢復有效內容，個人標註隔離不被管理操作繞過。
40. 老師發起及結束簽到、查看已簽／未簽；學生在開放期提交一次並可安全重試，未開放、已結束、訪客及無權請求均被拒絕。
41. 老師建立、發布及結束單選、多選、判斷及投票活動；學生提交一次且不可修改，投票無正確答案，客觀題結束後才向學生顯示答案。

43. 老師確認結束課堂後停止所有互動及加入；老師查看授權摘要，學生課後只查看本人標註及相關老師回覆，重複結束保持冪等。

## 4. 跨任務資料與安全要求

1. 帳號至少綁定一個已驗證手機號碼或電子郵件；手機只接受 `+852` 8 位本地號碼並統一保存為 `+852XXXXXXXX`。
2. 手機號碼及電子郵件分別執行唯一性校驗；服務端資料約束是最終防線，待驗證重試及並發提交均不得建立重複有效帳號。
3. 顯示名稱 trim 後為 2–30 字元；角色以服務端帳號記錄為準，註冊後不得由使用者自行切換。
4. 密碼支援 Unicode，按字元數限 8–64 位，不 trim、不正規化，採用 `zxcvbn` 至少 3 分；密碼散列採用市場通用安全方案。
5. 註冊及密碼重設驗證碼由服務端生成及校驗，綁定用途及識別資料；有效期、重發間隔及嘗試次數可配置，驗證成功或過期後不可重用。

| BRK-D-038 | 保留、匯出及刪除 | 課堂結束起保留 7 天；老師及學生分別匯出獨立 PPT／PPTX，使用指定檔名及瀏覽器預設下載路徑；刪除針對整個課堂，不影響原始課程及原檔，TXT 刪除記錄獨立長期保存 |
| BRK-D-044 | 課堂碼及失效規則 | 課堂碼固定為排除 `0/O/1/I` 的 6 位大寫字母及數字；只在課堂進行中有效，結束立即失效，不提供重新生成或自訂有效期；輸入自動 trim 及轉大寫，不接受空格或連字號；同一帳號及來源 IP 的無效嘗試採可配置限流 |
| BRK-D-045 | 授課控制頁及建立邊界 | 控制頁至少顯示課堂名稱、所屬課程、目前頁碼／總頁數、上一頁／下一頁、第一頁內容及可開關加入資訊；首頁載入失敗時老師可重試，學生及訪客顯示「等待第一頁載入」且不顯示錯誤頁內容；開始失敗保留所選課件及課程上下文；服務端須確認即時通道可用才可標記進行中並產生可加入課堂 |
| BRK-D-046 | 共享層及回覆可見範圍 | 當前課堂已加入學生可查看共享層及相關老師回覆；訪客完全不可查看共享層、老師回覆或活動細節；學生本期不可回覆；所有讀者仍不得取得個人標註或他人非公開提交 |
| BRK-D-047 | 即時傳輸及狀態版本 | 即時傳輸採 WebSocket 類通道；服務端以遞增狀態版本及權威快照處理亂序、重複及重連；300 ms 量測起訖為操作端發送事件至其他課堂端完成更新，使用預設網絡及合計 100 並發 |
| BRK-D-048 | 標註位置、群組及篩選 | 位置以頁面相對寬高的歸一化座標保存，並關聯課件版本及頁碼；群組以明確群組 ID 關聯，不依距離自動合併；獨立共享標記可由作者移動位置但不按距離改組；篩選為全部／可見／隱藏，只改變視圖不修改資料 |
| BRK-D-049 | 清除共享標註語義 | 老師確認後清除目前頁共享展示內容；清除後不可經介面恢復，個人標註及其他頁內容不受影響；清除狀態須同步至共享層讀者，且不被延遲或亂序事件復活 |
| BRK-D-050 | 活動題目、答案及結束配置 | 題目 trim 後 1–200 字元；選項 2–6 個且每項 trim 後 1–100 字元；單選恰一個正確答案、多選至少一個、判斷固定正誤、投票無正確答案；同一課堂同時只開一個簽到或答題活動，結束後遲交拒絕；不含完整題庫、計分或匿名投票 |

| BRK-D-052 | 匯出版式及產生方式 | 教師及學生均產生系統另行生成的獨立 PPT／PPTX，任務於背景非同步執行且可安全重試；版式至少呈現課堂資料、標註／回覆作者角色及時間；課堂名或老師名中的非法檔名字元以下底線安全替換；不含像素級還原保證 |
| BRK-D-053 | 7 天到期及刪除執行 | 7 天按服務端時間自課堂結束起計 168 小時，到期後關閉課堂內容查看及匯出檔下載；TXT 刪除記錄獨立保存，本期不開放老師、學生或訪客查看入口；不新增課堂恢復功能 |
| BRK-D-054 | 共享授權收回後的既有內容 | 收回授權後既有共享標註保留且由老師管理，但該學生不得再新增、修改、移動或刪除共享內容；本期不隱藏、撤回或由學生刪除既有內容；個人標註不受影響 |
