## 1. 測試目標與範圍

本文件覆蓋 6 天可示範 MVP 的 P0 驗收，核心路線為：帳號註冊（免驗證碼）／登入／登出 → 老師建立及查看課程 → 老師單檔上傳 PPT／PPTX → 背景轉換及預覽 → 已加入課程學生在本人課程頁預覽成功課件並管理本人個人文字標註 → MVP 基礎視覺、技術及品質驗收。

### 1.1 本期包含

- REQ-001 開放註冊（免驗證碼）、登入、工作階段、忘記密碼（舊密碼驗證直接重設）及登出；註冊及密碼重設的擁有者驗證碼均屬後續優化。
- REQ-002 老師建立課程、產生固定 8 位課程碼、複製及查看本人課程列表。
- REQ-004 老師單檔上傳 `.ppt`／`.pptx`、校驗、私有保存及課件列表。
- REQ-005 自動背景轉換、狀態追蹤、逐頁預覽、失敗／逾時重試及存取控制。
- REQ-010 已加入課程學生在本人課程頁管理本人個人文字標註；採用已確認的非課堂例外。
- TASK-333 課程頁學生預覽入口。

- NFR-012、NFR-013、NFR-015 的 MVP 主題、rem 及前端建置／靜態品質驗收。

## 2. 測試環境與通用前置條件

- 前端：`apps/web` 依 lockfile 安裝後以 `corepack pnpm dev` 啟動；正式建置以 `corepack pnpm build` 驗證。
- 後端：`apps/api` 執行 `uv sync` 後以 `uv run uvicorn app.main:app --reload` 啟動。
- API 契約：REST 使用 `packages/contracts/openapi.json` 及前端生成型別作為基準，不手動修改生成物。
- 資料：每輪執行前重置測試資料庫及私有課件儲存；帳號、課程成員及演示課件由初始化程序建立。
- 外部依賴：SMS／電郵及隔離轉換服務使用可控測試替身或沙箱；外部故障以測試替身注入。
- 權限：除正面登入外，越權用例必須同時檢查前端入口與服務端 API，不能只依賴隱藏按鈕。
- 私隱：驗證碼、密碼、原始課件、個人標註及私密資料不得出現在日誌、前端持久化儲存或未授權回應。
